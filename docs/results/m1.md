## Shared vectors

Command: `python spec/generate_vectors.py --check` (passes: committed vectors match the generator).

| Structure | Cases | Operations | Reference model |
|---|---|---|---|
| `min_heap` | 7 | 1,223 | `heapq` |
| `hash_map` | 7 | 1,917 | `dict` |
| `lru_cache` | 7 | 1,824 | `collections.OrderedDict` |
| **Total** | **21** | **4,964** | |

Each structure has four hand-written edge cases (empty pops, updates that must not evict,
remove-then-reinsert, growth past the initial capacity) and three seeded random cases.

## Quality control (DMAIC)

| Phase | This repository |
|---|---|
| Define | Hand-written structures in several languages drift apart in edge cases that per-language unit tests rarely notice, which affects developers who port code between Java, Python and JavaScript. M1 counts when one JSON spec per structure, generated from standard-library reference models, is replayed by a runner in each language and all three pass the same files; the RFC's measure is 21 shared cases (about 5,000 operations) passing in all three ([RFC 0001](../rfc/0001-design.md)). |
| Measure | `python spec/generate_vectors.py --check`, `mvn verify`, `pytest` and `node --test` on an Intel Core i7-13700H with Windows 11, repeated with `pip-audit` and an OSV.dev check of the resolved Maven dependencies on 2026-10-06. 21 cases with 4,964 operations; 22 Java, 23 Python and 23 JavaScript tests passed, 0 failed. |
| Analyze | All three implementations returned the same result for every one of the 4,964 operations, so the target was met. One defect was found in the recheck: 17 advisories in the test-scope `jackson-databind` 2.18.2 and `jackson-core` used to read the vectors. Benchmarks and property tests are not measured yet (M2). |
| Improve | Jackson was upgraded to 2.22.3; the OSV.dev check then found no advisories. |
| Control | The `ci` workflow's `build` job runs `make ci` (vector staleness check, `mvn compile`, ruff with security rules and format check, `node --check` and the three test suites) and `make audit` (`pip-audit`, and OSV-Scanner on a CycloneDX SBOM of every resolved Maven dependency, added 2026-10-07) on every push and pull request, with every action pinned to a commit SHA. In the code, expected results come only from `heapq`, `dict` and `OrderedDict` models with fixed seeds (ADR 0002), and a disagreement fails that language's build with the step number and operation. |
